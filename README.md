# 💳 Payment Gateway Application

This is a full-stack **Payment Gateway** system that simulates secure payment handling for e-commerce or fintech applications. It consists of a **Spring Boot backend** and a **frontend user interface**, both located within the same repository.

---

## 📌 Project Overview

### 🔧 Backend (Spring Boot)
The backend is built using **Java + Spring Boot** and provides RESTful APIs for:
- Initiating and processing payments
- Simulating payment success/failure
- Asynchronous transaction handling

### 🖼️ Frontend
The frontend provides an interactive user interface that:
- Allows users to enter payment details
- Submits payments via REST API
- Displays transaction status (success/failure)
- Clean, responsive design for demo purposes
